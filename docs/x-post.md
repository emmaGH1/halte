# main post

i built halte for @QoreChain's build before q-day hackathon. it's a stolen-watch check. every watch gets a passport tied to its owner's post-quantum key (ML-DSA-87) that dealers, marketplaces and insurers can check before a purchase.

if it's stolen, the owner signs one report from their phone. from the next block, every check says “do not buy.” deals arranged before the theft stay dead after recovery.

after q-day, a thief with a cracked ordinary wallet key still can't report, unfreeze or sell it. qorechain verifies the post-quantum signature on chain.

it's live on qorechain's diana testnet. no wallet needed: https://halte-roan.vercel.app
film: https://vimeo.com/1250612041
