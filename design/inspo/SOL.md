# Halte design references

Start with **The Void Seal**. It gives judges a physical cue for the hardest beat in the demo: the owner gets the passport back, while the dealer’s original offer stays void. Keep the watch’s identifying details in the same place through each state change so the audience can recognize the same item at a glance.

## Mood directions ranked for judges

### 1. The Void Seal

Build the mobile view around a passport and its attached dealer slip. On confirmed theft, the passport gains a frozen band and the slip takes a permanent VOID imprint over its original offer ID.\
When the owner recovers the passport, lift the band while the imprint stays. The final frame reads “Passport active” above “Original offer void.”

**Palette and type** · Graphite `#182126`, cold silver `#D4DEE1`, blue-green `#006B62` for active, and vermilion `#BA321F` for refusal. Instrument Sans for status and actions, IBM Plex Mono for the slip’s identifiers.

**References** · [3M VOID labels](https://multimedia.3m.com/mws/media/526389O/3m-tamper-evident-label-materials.pdf) · [Bank of England polymer banknotes](https://www.bankofengland.co.uk/quarterly-bulletin/2021/2021-q3/our-new-banknotes-the-journey-from-design-to-launch) · [HM Passport Office recovered passports](https://www.gov.uk/government/publications/lsr-examination-replacing-lost-stolen-and-recovered-passports/lsr-examination-replacing-lost-stolen-and-recovered-passports-accessible)

### 2. The Inspection Window

Use a fixed inspection frame for the watch serial and a full-width decision strip for the dealer. The same frame hosts a fresh check before payment and a repeat check after the owner reports theft.\
During lookup a single sweep crosses the identifier. When the result arrives the strip changes from “Can buy” to “Do not buy” with the reason and check time directly below.

**Palette and type** · Midnight `#121C24` around the aperture, frosted blue `#DFEBEF` for the evidence area, jade `#007256` and rust `#A62E24` for the decision strips. Geist for body, Archivo Narrow for wide decision labels.

**References** · [The Watch Register search certificates](https://www.thewatchregister.com/frequently-asked-questions/) · [Dribbble passport scan flow](https://dribbble.com/shots/27564571-ID-Passport-Verification-Flow) · [Ticketmaster SafeTix](https://help.ticketmaster.com/hc/en-us/articles/26584309038353-Why-do-my-tickets-have-a-moving-barcode)

### 3. Same Request, Two Signatures

Stage the Q-Day beat as two attempts to recover the same passport, each in the same view. Keep the recovery action and item fixed so the judge sees the copied wallet credential arrive and the required signature check fail.\
Repeat with the owner’s registered post-quantum signature, then reveal the accepted result. Put “ML-DSA-87” and the QoreChain proof behind a details tap.

**Palette and type** · Midnight ink `#191B2C`, chalk blue `#E7EEF5`, teal `#08665B` for acceptance, poppy `#C03927` for refusal. Bricolage Grotesque for the attempt and outcome, Geist for instructions and details.

**References** · [The Pudding’s interactive prediction demo](https://pudding.cool/2019/04/text-prediction/) · [Phantom warning screens](https://docs.phantom.com/developer-powertools/domain-and-transaction-warnings) · [Passkeys.io demo](https://www.passkeys.io/)

### 4. The Pocket Evidence File

Use a narrow, timestamped case log with a fixed passport identifier and each status change set as a receipt line. Keep the latest dealer decision above the log so the next action is immediately clear.\
Tap an event to unfold its signature check or chain receipt. Leave the denied attempt and void offer in the log after recovery so the judge can replay the sequence.

**Palette and type** · Ink `#13252C`, ice `#E9F1F4`, navy `#254766` for the log gutter, and oxide `#AA3429` for adverse outcomes. Source Sans 3 with IBM Plex Mono timestamps and transaction IDs.
